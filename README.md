#  Финансовый Дашборд

Проект предоставляет API для комплексного анализа персональных финансов, включая:
- Анализ банковских операций 
- Мониторинг курсов валют 
- Отслеживание котировок акций 


## Модуль external_api
## 🛠 Функционал

### 1. Курсы валют
#### `get_exchange_rates(base: str, currencies: Sequence[str], timeout: float, max_retries: int) -> Optional[list[Dict]]`
- **Назначение**: Получение текущих курсов валют
- **Параметры**:
  - `base`: Базовая валюта (по умолчанию "RUB")
  - `currencies`: Список валют для конвертации (по умолчанию USD, EUR, CNY)
  - `timeout`: Таймаут запроса (20 сек)
  - `max_retries`: Макс. попыток (2)
- **Формат ответа**:
  `[{
      "currency": "USD",
      "exchange_to": "RUB", 
      "exchange_rate": 90.25
  }]`

#### `def get_stock_rates_finnhub(stock: Sequence[str] = ("MSFT", "AAPL", "TSLA"), timeout: float = 20.0, max_retries: int = 2`

- **Назначение**: Получение актуальных котировок акций через API Finnhub
- **Параметры**:
  - `base`: Базовая валюта (по умолчанию "RUB")
  - `currencies`: Список валют для конвертации (по умолчанию USD, EUR, CNY)
  - `timeout`: Таймаут запроса (20 сек)
  - `max_retries`: Макс. попыток (2)
- **Формат ответа**:
`[
    {
        "ticker": "AAPL",
        "current_price": 175.50,    # Текущая цена
        "change": 1.25,            # Изменение цены
        "percent_change": 0.72,     # Изменение в процентах
        "high": 176.80,            # Максимум дня
        "low": 174.20,             # Минимум дня
        "open": 175.00,            # Цена открытия
        "previous_close": 174.25    # Цена закрытия предыдущего дня
    },`

## 🛠 Функционал

### 📅 Временные функции
- `get_current_time() -> str`  
  **Описание**: Возвращает текущую дату и время в формате 'YYYY-MM-DD HH:MM:SS' с автоматическим определением временной зоны системы. При ошибке определения зоны автоматически переключается на UTC.  
  **Формат вывода**: `"2023-12-31 23:59:59"`

- `get_greeting() -> str`  
  **Описание**: Генерирует контекстное приветствие на основе текущего времени суток:  
  - 05:00-11:59 → "Доброе утро"  
  - 12:00-16:59 → "Добрый день"  
  - 17:00-22:59 → "Добрый вечер"  
  - 23:00-04:59 → "Доброй ночи"  
  **Особенности**: Использует `get_current_time()` для определения времени

### 💳 Анализ операций
- `process_cards(transactions: List[Dict]) -> List[Dict]`  
  **Описание**: Агрегирует данные по банковским картам:  
  - Извлекает последние 4 цифры номера карты (маскирует полный номер)  
  - Суммирует расходы по каждой карте (только отрицательные операции)  
  - Аккумулирует кэшбэк по всем операциям  
  **Формат вывода**:  
  ```python
  [{
      "last_digits": "1234",
      "total_spent": 15000.0,
      "cashback": 750.0
  }]

###  Финансовые данные
